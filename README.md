# AI-Powered Market Research Portal

A professional-grade intelligence engine that converts raw market data into strategic consulting frameworks (SWOT, PESTLE, Porter's 5 Forces, BCG Matrix, McKinsey 7S).

## 🚀 Features
- **Real-Time Intelligence**: Powered by Gemini Pro with Google Search Grounding.
- **Dynamic Frameworks**: Automatically populates 5+ industry-standard strategic views.
- **Shareable Reports**: Generate unique URLs to share intelligence reports instantly without a database.
- **Premium UI**: Sleek, glassmorphic dark mode for high-stakes decision makers.

## 🛠 Setup & Installation
1. Clone this repository or download the files.
2. Open `index.html` in any modern web browser.
3. Click the **Settings** icon and enter your **Gemini API Key**.

## 🌐 Deployment
This project is ready to be hosted on **GitHub Pages**, **Netlify**, or **Vercel**. Simply upload the folder and your portal is live!
